# Aptis
Ứng dụng ôn thi Aptis với 5 module Listening, Speaking, Writing, Reading, Vocabulary. Theo dõi tiến độ học tập, đồng bộ trên mọi thiết bị qua Netlify.
# Ôn Thi Aptis

Ứng dụng web hỗ trợ ôn thi Aptis, gồm 5 module luyện tập tương ứng với các kỹ năng thi:

- 📖 **Reading**
- ✍️ **Writing**
- 🎧 **Listening**
- 🗣️ **Speaking**
- 📝 **Vocabulary**

## Tính năng
- Theo dõi tiến độ ôn tập theo từng module
- Đồng bộ tiến độ trên mọi thiết bị (deploy qua Netlify)
- Giao diện đơn giản, dễ sử dụng

## Công nghệ
HTML/CSS/JS thuần
